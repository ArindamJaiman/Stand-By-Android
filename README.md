# StandBy Pro

StandBy Pro is a premium Android application that recreates the overall functional concept of Apple's iOS StandBy experience on Android devices. It uses native Android APIs, adheres to modern Android design conventions, and provides an immersive edge-to-edge landscape display featuring customizable clocks, widgets, and intelligent ambient sensors.

## Features
- **Immersive Ambient Display:** Activates automatically based on device charging state and physical orientation (accelerometer).
- **Customizable Clocks:** Beautifully crafted digital and analog clock faces.
- **Ambient Intelligence:**
  - **Night Mode:** Utilizes the hardware light sensor to transition the UI to a deep, monochrome red in low-light environments.
  - **Burn-In Protection:** Slowly shifts OLED pixels to prevent screen degradation.
  - **Auto-Dimming:** Dims the interface after periods of inactivity.
- **Target Devices:** Optimized for Nothing Phone (2a) Plus (Nothing OS) and Samsung Galaxy Tab (LineageOS).
